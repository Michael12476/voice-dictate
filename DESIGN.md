# Voice Dictate design

The app uses a small charcoal pill with a purple-to-blue waveform, matching the logo. It stays close to the bottom of the screen without taking focus. Live words and polishing share the same pill; Copy appears after a detected interruption.

Setup uses a plain Windows terminal wizard and a desktop shortcut. Each user chooses their local model, completes their own Codex sign-in, and optionally connects their own phone. Personal values stay in ignored files beside the app.

The settings window keeps its existing dark Windows appearance. Text is rendered as text, and its native bridge only reads or writes the app's fixed settings files.
